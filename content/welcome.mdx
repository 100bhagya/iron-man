# Building Iron Man

This space will host technical articles and case studies. Content lives in `/content` as MDX files, separate from UI and business logic.

## Principles

- **Modular boundaries** — layout, components, data, and future interactive tools stay isolated.
- **Dark-first** — minimal palette with arc-reactor cyan accents for focus and hierarchy.
- **Performance** — server components by default; client islands only where interactivity is required.
